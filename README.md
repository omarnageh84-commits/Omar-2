# App-Omar - نظام إدارة عربي RTL

تطبيق ويب عربي 100% لإدارة اليومية والحضور والمهام، مربوط بـ Google Drive و Google Sheets.

## المميزات
- ✅ 4 شيتات: اليومية / الحضور / المهام / الرئيسية - عربي RTL
- ✅ المهام: أهمية (مهم/متوسط/عادي) + ملاحظات داخلية + مهام فرعية + ألوان
- ✅ Sync تلقائي لـ Google Sheets عبر Apps Script
- ✅ تصميم موبايل Phone Shell + ثيمات متعددة
- ✅ حفظ محلي + سحابي
